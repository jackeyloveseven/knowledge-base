# ID 保持在图像生成中的工程方法 — 大规模训练视角

> 触发日期：2026-06-22 | 更新：同日（修正推理延迟+25/26年论文补充）
> 触发人：李承燕
> 约束：商业部署，推理 ≤10s（目标 6s），不接受任何 adapter/ControlNet 推理开销。ID 保持必须内建在模型权重中。

## 一句话总结

25-26 年核心共识：**训练时把人脸识别 embedding（ArcFace）作为 AdaLN condition 注入 DiT，搭配 contrastive identity loss 或 GRPO reward，推理时单次 forward 完成。** 动漫场景靠训练数据驱动，不需要 ArcFace。

## 25-26 年关键论文（按与你项目的相关度排序）

### ⭐⭐⭐⭐⭐ AnyPhoto (2603.14770, 2026.03)

**跟你做的最像。DiT + ArcFace→AdaLN，开箱参考。**

> "AdaLN-style identity-adaptive modulation from face-recognition embeddings"

- DiT finetuning framework，和 Qwen Image Edit 同架构
- ArcFace 512d → AdaLN 注入 identity-adaptive modulation
- Identity-isolated attention 防止多 ID 干扰
- 训练：conditional flow matching + embedding-space face similarity loss
- 防 copy-paste：reference-face replacement + location-canvas degradation
- **推理：零额外模块，单次 forward**

### ⭐⭐⭐⭐⭐ Customized-GRPO (2510.18263, 2025.10)

**你已经在做 GRPO，这篇直接告诉你 GRPO 怎么做 ID。**

> "Naive GRPO leads to competitive degradation — conflicting gradient signals between ID fidelity and prompt adherence"

两个创新：
- **SARS**（Synergy-Aware Reward Shaping）：非线性 reward 聚合，惩罚冲突信号、放大协同信号
- **TDW**（Time-Aware Dynamic Weighting）：早期 timestep 侧重 prompt-following，晚期侧重 identity preservation

这跟你训 GRPO 的方式直接相关——reward 不能简单线性加和，ID 保持和编辑质量存在竞争关系。

### ⭐⭐⭐⭐ WithAnyone (2510.14975, 2025.10)

**发现并命名了「copy-paste」问题——模型直接复制参考人脸而不是保持 ID。这可能是你训练中最容易踩的坑。**

> "Reconstruction-based training leads to copy-paste: the model directly replicates the reference face rather than preserving identity across natural variations"

三个贡献：
1. 构建 MultiID-2M 数据集（多 ID 配对数据）
2. Benchmark 量化 copy-paste 程度和 ID fidelity-diversity tradeoff
3. **Contrastive identity loss**：利用配对数据平衡保真度和多样性

### ⭐⭐⭐⭐ Diff-PC (2602.00639, 2026.02)

零样本人像定制，identity-preserving + 3D-aware。DiT 可控扩散。

### ⭐⭐⭐ DiffSwap++ (2511.05575, 2025.11)

3D latent-controlled 换脸。虽然换脸不是你的主场景，但其 identity-preserving 技术栈（latent control + ID loss）可参考。

### ⭐⭐ ARGUS (2606.11670, 2026.06)

视频级 ID 保持。Stacked Multi-View Identity Mosaic Injection。侧重 video，但 identity mosaic 思路（多视角融合 ID 特征）可能对静态图也有用。

## 跟你项目直接对口的路线

### 路线 1：DiT + ArcFace→AdaLN（参考 AnyPhoto）

```
训练时：
  image → face detection → ArcFace 512d → MLP → AdaLN scale/shift
  AdaLN = timestep_condition + text_condition + id_condition（直接相加）

推理时：
  image → face detection → ArcFace → AdaLN（内建在模型权重里）
  总开销：~100ms（仅 face detection）
```

**关键防 copy-paste 技巧**（AnyPhoto + WithAnyone）：
1. 训练时随机替换 reference face，防止模型死记某张图
2. Contrastive identity loss：同人不同图→拉近特征，不同人→推远
3. 不用 reconstruction-based training（会导致 copy-paste）

### 路线 2：GRPO 训 ID 保持（参考 Customized-GRPO）

```
reward = w_prompt * prompt_similarity + w_id * id_similarity

但这里 w 不能是常数！
- 早期 timestep（0~0.5T）：w_prompt > w_id（先保证编辑效果）
- 晚期 timestep（0.5T~1.0T）：w_id > w_prompt（人脸成形后再加 ID 约束）
- 用 SARS 非线性聚合代替线性加和
```

### 路线 3：纯数据驱动（动漫/非真人 / Qwen Image Edit 编辑场景）

```
训练数据构造：
  (原图, "改背景→海滩", 编辑后图人脸不变)
  (原图, "换发型", 编辑后图人脸不变)
  (原图, "变老", 编辑后同一个人老了)

模型自然学会：instruction 没提人脸→人脸不能动
推理：正常脚本，零额外开销
```

## 动漫场景特别说明

ArcFace 对动漫完全没用（训在真实人脸数据上）。动漫 ID 保持靠：
1. **训练数据驱动**（主力）：编辑模型的训练 pair 教会模型"不该改的别动"
2. **CLIP/DINOv2 特征**（备选）：比 ArcFace 通用，对动漫有一定感知，推理多 ~50ms
