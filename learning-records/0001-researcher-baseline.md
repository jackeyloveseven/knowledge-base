# 研究员背景与知识基线确立

用户是图像生成方向研究员，已通过 25 篇深度笔记（含多模型交叉审核）建立了扎实的书面知识体系。具体覆盖：SFT/RL/OPD 训练范式、KL 散度统一框架、GRPO、DMD/CM 蒸馏、LoRA 变体（Lightning/Glance）、视觉编码器（CLIP/SigLIP/DINO）、工程经验（ID 保持、调参、Model Merge）。

笔记质量高——包含数学推导、multi-model 审核意见、实践建议，但这些知识以"可查阅"形态存在，尚未经过主动检索强化。学习任务是从参考材料升级为内化理解。

**Implications**: 课程跳过基础讲解阶段，直接进入检索练习。每课假设用户已读过相关笔记，不重复讲解内容，专注强迫主动回忆与批判分析。
