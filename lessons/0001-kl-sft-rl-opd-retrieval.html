Q1 回忆

SFT 的损失函数是：

L_SFT = −E_{(x,y)~D} [log p_θ(y|x)]

请写出完整推导，说明 最小化 L_SFT 等价于最小化哪个方向的 KL 散度，采样分布是谁。

答案

展开 L_SFT：

L_SFT = −E_{x~D} [ Σ_y p_data(y|x) · log p_θ(y|x) ] = E_{x~D} [ H(p_data(·|x)) + KL(p_data(·|x) ‖ p_θ(·|x)) ] = const + E_x [ KL(p_data ‖ p_θ) ]

因此：最小化 L_SFT ⟺ 最小化 Forward KL(p_data ‖ p_θ)。

采样分布是 p_data（训练数据，固定）——KL(P‖Q) 从 P 采样，这就是"Forward"的含义。

来源：MiniLLM (arXiv:2306.08543) §3.1 明确推导了这个等价性。

Q2 回忆

用"谁采样"+"惩罚什么"+"行为特征"三个维度，对比 Forward KL 和 Reverse KL 的根本差异。

不要看笔记，自己先填出这张表的内容：

维度Forward KL(P‖Q)Reverse KL(Q‖P)
谁采样??
重罚什么情形??
行为特征??
在图像生成中对应??
答案
维度Forward KL(P‖Q)Reverse KL(Q‖P)
谁采样数据分布 P（固定）模型自己 Q（在线）
重罚什么Q 在 P 有概率处概率低（漏覆盖）Q 在 P 概率极低处概率高（越界）
行为特征Mode-covering（广撒网）Mode-seeking（聚焦高 reward 区）
图像生成SFT 微调；混质数据→图像模糊GRPO/RL 对齐；可能 diversity 下降

记忆口诀：Forward KL = "不能漏"（覆盖所有模式）；Reverse KL = "不能越"（不生成 P 不认可的东西）。

Q3 应用

RLHF PPO 的目标函数为：

max E[ r(x,y) − β · KL(π_θ(·|x) ‖ π_ref(·|x)) ]

KL 惩罚项是 Forward 还是 Reverse KL？

请解释：（1）为什么是这个方向；（2）这个惩罚项在训练中实际起什么作用；（3）β 太大/太小分别会发生什么。

答案

是 Reverse KL。KL(π_θ ‖ π_ref) 的采样分布是 π_θ（当前 policy 自己），所以是 Reverse KL。

作用：reward 项把 π_θ 拉向高 reward 区域，KL 惩罚项把 π_θ 拉回 π_ref 附近，防止 reward hacking（策略偏离太远生成奇怪内容）。二者形成 tug-of-war。

β 的 tradeoff：

  • β 太大：KL 约束过紧 → 策略无法探索 → 退化成类 SFT 行为，reward 提不上去
  • β 太小：KL 约束过松 → reward hacking → 策略崩坏（图像生成中典型表现：画面失真但 reward 高）

RL's Razor (arXiv:2509.04259) 进一步表明：on-policy 训练天然具有低 KL 偏置，这是 RL 比 SFT 遗忘更少的关键机制。

Q4 应用

用"老师做题/学生做题"的比喻，在一句话内说出 On-Policy Distillation (OPD) 和传统 Knowledge Distillation (KD) 的根本区别。

然后回答：这个区别在 DiT latent diffusion 模型（非自回归）中重要吗？为什么？

答案

一句话：传统 KD 是"老师做题、学生抄答案"（off-policy）；OPD 是"学生做题、老师当场批改"（on-policy）。

在 DiT latent diffusion 中的重要性：

⚠️ Exposure Bias 在这里不是主要动机。Exposure Bias (O(L²) 误差累积) 是自回归模型的问题——每个 token 依赖之前的 prefix。但 DiT 的去噪过程是 Markovian（每步只依赖当前噪声状态和 timestep），不是自回归的，天然没有 exposure bias。

OPD 在 DiT 中的真正价值是：提供比稀疏 RL reward 更 dense 的监督信号——每个去噪步骤都有教师的 transition 分布作为目标，信息量远大于最终的 scalar reward。

这个区分来自 Claude Opus 的审核意见（笔记 10 末尾），是重要的认知校正。

Q5 批判分析

有人说：

"SFT 之后，看 validation loss 收敛了、SFT score 也很高，这时候切 RL 最合适。"

这个说法有什么问题？至少指出两个 failure mode。

答案

这是 Quagmires in SFT-RL (arXiv:2510.01624) 明确指出的陷阱，至少有两个 failure mode：

Failure 1 — SFT score 高 ≠ 好的 RL 起点：SFT score 偏向简单、同质化数据，可能只是在记忆常见模式，对真正需要泛化的 RL 任务没有预测力。用 Pass@large_k 或 generalization loss 更可靠。

Failure 2 — SFT 过多 → Plasticity Loss：长时间 SFT 会压缩模型的权重更新空间（plasticity），导致 RL 阶段梯度无法有效改变参数，reward 无论如何都提不上去。（When RL Fails after SFT, arXiv:2606.09932）

隐含问题（bonus）：SFT 的 Forward KL 特性会使模型记忆训练分布。SFT score 高意味着拟合得好，但这正是 mode-covering 的副产品——对 OOD prompt 泛化差（SFT Memorizes, RL Generalizes, arXiv:2501.17161）。

建议做法：控制 SFT epoch，同时监控 generalization loss 而非训练 loss；或用 Rejuvenation（base-anchored model fusion）救回 plasticity。

Q6 迁移

你在用 GRPO 训练一个 DiT 图像编辑模型，reward = CLIP-I（图文对齐）+ DINO（结构保留）的加权组合。

训练 3000 步后，你观察到：模型输出开始收敛到高饱和度、高对比度风格，之前能生成的低饱和柔和风格逐渐消失。

请：（1）用 KL 框架诊断这个现象的根本原因；（2）提出至少两种解法，说明各自的 tradeoff。

答案

诊断：这是 Reverse KL 的 mode-seeking 行为 与 reward 偏差 的叠加效应。

GRPO 优化 Reverse KL(π_θ ‖ π_ref)，天然倾向 mode-seeking——模型聚焦高 reward 区域，放弃低 reward 模式。如果 CLIP-I reward 天然偏好高对比度（CLIP 在训练数据中这类图像更多），模型会系统性地漂向这个风格，低饱和风格概率坍缩。

解法 1 — 增大 β（KL 惩罚系数）：加强对 reference policy 的约束，限制策略偏移幅度。Tradeoff：reward 提升速度变慢，可能需要更多步数才能收敛。

解法 2 — 修复 reward 偏差：检查 CLIP-I reward 的分布偏差，加入 diversity reward（如生成样本间的 LPIPS 距离），或用 f-DPO 把底层散度从 Reverse KL 改为 Forward KL 以保留多样性。Tradeoff：reward 工程复杂度上升，需要额外验证。

解法 3 — OPD（如果条件允许）：分别训练"CLIP 对齐教师"和"风格多样性教师"，然后 OPD 蒸馏到学生，避免 reward conflict 的跷跷板效应。Tradeoff：训练成本大幅上升（多个 teacher 同时在线需要显存），参考笔记 01 中 Gemini 审核意见的 Semi-On-Policy 退让方案。
